The Daily Brief documentation
=============================

Documentation for the Django news application built for the HyperionDev
capstone. The pages below are generated directly from the docstrings written
in the source files, so the code comments and this documentation can never
disagree with each other.

Project layout
--------------

``newsproject`` holds the Django project settings and root URL configuration.
The ``news`` app contains everything else: the database models, the REST API
serializers and viewsets, the server-rendered HTML views, and the admin and
signal registrations.
